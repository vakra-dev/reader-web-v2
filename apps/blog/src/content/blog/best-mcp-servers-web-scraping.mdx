If you use Claude Code, Cursor, or any other AI coding tool and need it to access the web, you need an MCP server. The Model Context Protocol gives your AI tools a standardized way to call external services, and web scraping MCP servers are quickly becoming essential infrastructure for developers building AI applications.

As of December 2025, the MCP ecosystem had over 97 million monthly SDK downloads and 10,000 active servers, with support across Claude Desktop, Claude Code, Cursor, Windsurf, VS Code, ChatGPT, Gemini, Microsoft Copilot, and Codex. This guide covers the 7 best MCP servers for web scraping, what each one exposes, and how to install them.

## What Is MCP and Why It Matters

The Model Context Protocol is an open standard introduced by Anthropic on November 25, 2024 and donated to the Linux Foundation's Agentic AI Foundation on December 9, 2025. The co-founders of the foundation include Anthropic, OpenAI, and Block.

MCP solves a specific problem: without it, every AI tool would need custom integrations for every external service. That is an N times M problem where N AI tools each need M custom connectors. MCP replaces that with a single protocol. Any MCP-compatible client can call any MCP server using the same interface.

For web scraping, this means your AI coding assistant can scrape pages, crawl sites, search the web, and automate browsers through a single installed MCP server, regardless of which AI tool you use. Install once, use everywhere.

## How to Install an MCP Server

Most MCP servers follow the same installation pattern. You add an entry to your AI tool's configuration file that tells it where to find the server and how to authenticate.

The standard format looks like this:

```json
{
  "mcpServers": {
    "server-name": {
      "command": "npx",
      "args": ["-y", "server-package-name"],
      "env": {
        "API_KEY": "your-api-key-here"
      }
    }
  }
}
```

Where to find the config file depends on your AI tool. For Claude Code, it is `~/.claude/claude_desktop_config.json`. For Cursor, it is in the Cursor settings under MCP. For VS Code, it is in the MCP extension settings.

After adding the configuration, restart your AI tool. The MCP server's tools will appear in the tool list and your AI assistant can call them during conversations.

## 1. Reader MCP

[Reader](https://reader.dev)'s MCP server exposes the three core primitives of the Reader platform: read, crawl, and browse.

The read tool takes any URL and returns clean, LLM-ready markdown. JavaScript rendering, anti-bot bypass, and content extraction happen automatically. The crawl tool extracts content from multiple pages across a domain with configurable depth and pattern filtering. The browse tool creates cloud browser sessions with full CDP compatibility, allowing your AI assistant to log into portals, navigate authenticated pages, and interact with the web through Playwright or Puppeteer.

Reader is open source under Apache 2.0. The entire platform, including the MCP server, can be self-hosted. The managed platform at reader.dev offers 1,000 free pages per month.

The key differentiator is the combination of scraping and browser automation in a single MCP server. Most scraping MCP servers give you page content. Reader also gives you a live browser you can control.

**Install:**
```json
{
  "mcpServers": {
    "reader": {
      "command": "npx",
      "args": ["-y", "@vakra-dev/reader-mcp"],
      "env": {
        "READER_API_KEY": "rdr_your_key"
      }
    }
  }
}
```

## 2. Firecrawl MCP

Firecrawl's MCP server is the most feature-rich scraping MCP server available. It exposes 12 tools covering scrape, crawl, map, search, extract, agent, and browser session capabilities.

The scrape tool returns clean markdown from any URL. The crawl tool handles multi-page extraction with automatic link following. Map discovers all URLs on a domain. Search queries the web and returns full content from results. Extract uses AI to pull structured data based on natural language prompts or schema definitions. Agent performs multi-step browser tasks autonomously. Browser session creates a persistent browser context for complex interactions.

Firecrawl has the largest community in the AI scraping space with 148,000 GitHub stars on the main repository. The MCP server is well maintained and widely documented.

**Install:**
```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": {
        "FIRECRAWL_API_KEY": "your-key"
      }
    }
  }
}
```

## 3. ZenRows MCP

ZenRows' MCP server takes a different approach from the others. Instead of exposing multiple specialized tools, it provides a single tool with automatic anti-bot bypass and markdown output by default.

When your AI assistant calls the ZenRows MCP tool, it sends the URL and ZenRows' Adaptive Stealth Mode handles the rest. It automatically selects the right proxy type, fingerprint configuration, and rendering strategy. The output comes back as clean markdown ready for LLM processing.

This simplicity is both the strength and the limitation. You get reliable scraping with strong anti-bot bypass in a single tool call. But you do not get separate crawling, browser session, or extraction tools.

ZenRows is focused specifically on getting past anti-bot protection systems like Cloudflare, Akamai, DataDome, and PerimeterX. If your AI tool needs to scrape heavily protected sites, the ZenRows MCP server is the most specialized option for that task.

**Install:**
```json
{
  "mcpServers": {
    "zenrows": {
      "command": "npx",
      "args": ["-y", "zenrows-mcp"],
      "env": {
        "ZENROWS_API_KEY": "your-key"
      }
    }
  }
}
```

## 4. Bright Data MCP

Bright Data's MCP server provides web scraping backed by the largest proxy network in the industry (72 million+ residential IPs across 195 countries). It offers two modes: Rapid and Pro.

The server exposes tools for web search, page scraping, browser automation, and structured web data extraction. The browser automation tools let your AI assistant interact with pages through clicks, form filling, and navigation before extracting content.

Bright Data's strength is the proxy infrastructure behind the MCP server. For targets that block everything else, the depth and diversity of Bright Data's IP pool can make the difference. The platform is also SOC 2 and GDPR compliant, which matters for enterprise teams with compliance requirements.

**Install:**
```json
{
  "mcpServers": {
    "brightdata": {
      "command": "npx",
      "args": ["-y", "@anthropic-ai/brightdata-mcp"],
      "env": {
        "BRIGHTDATA_API_KEY": "your-key"
      }
    }
  }
}
```

## 5. Spider.cloud MCP

Spider.cloud's MCP server exposes 22 tools, the most of any scraping MCP server. Nine of these are browser automation tools for clicking, typing, scrolling, waiting, and navigating within browser sessions.

The scraping tools are powered by Spider's Rust-based engine, which achieves 182 pages per second for static content. Spider Browser scored 84.5% on Stealth Bench V1, the highest among tested browser platforms. Output formats include markdown, JSON, plaintext, XML, CSV, and JSONL.

Spider is open source under the MIT license (the spider-rs crawler). The breadth of exposed tools makes it the most capable MCP server for complex automation workflows where your AI assistant needs fine-grained control over browser interactions.

**Install:**
```json
{
  "mcpServers": {
    "spider": {
      "command": "npx",
      "args": ["-y", "spider-cloud-mcp"],
      "env": {
        "SPIDER_API_KEY": "your-key"
      }
    }
  }
}
```

## 6. ScrapingBee MCP

ScrapingBee's MCP server is hosted (URL-based rather than locally installed). It exposes tools for scraping text, scraping HTML, taking screenshots, and downloading pages, plus dedicated tools for Google Search, Amazon, Walmart, and ChatGPT data.

The dedicated site tools are ScrapingBee's unique advantage. No other scraping MCP server offers purpose-built tools for specific platforms. If your AI assistant needs to search Google, scrape Amazon product data, or extract Walmart listings, ScrapingBee's MCP server has dedicated tools optimized for each.

One consideration: the MCP server uses a hosted URL format with the API key embedded in the URL. Verify that your client handles this securely, as the key may appear in logs or history.

**Install (URL-based):**
```json
{
  "mcpServers": {
    "scrapingbee": {
      "url": "https://app.scrapingbee.com/mcp?api_key=YOUR_KEY"
    }
  }
}
```

## 7. Apify MCP

Apify's MCP server takes a unique approach by exposing access to Apify's marketplace of pre-built scrapers, called Actors. There are over 10,000 Actors available for specific sites and use cases: Amazon product scrapers, Google Maps extractors, LinkedIn profile scrapers, Instagram post collectors, and many more.

Instead of one general scraping tool, your AI assistant gets access to specialized scrapers that are optimized for specific sites. This is useful when you need data from a specific platform and want a scraper that handles that platform's unique structure and anti-bot measures.

The tradeoff is complexity. With thousands of Actors available, your AI assistant needs to know which one to use for each task. The MCP server handles Actor discovery, but the breadth of options can slow down simple scraping tasks that just need clean markdown from a URL.

**Install:**
```json
{
  "mcpServers": {
    "apify": {
      "command": "npx",
      "args": ["-y", "apify-mcp-server"],
      "env": {
        "APIFY_TOKEN": "your-token"
      }
    }
  }
}
```

## How to Choose

**Need browser automation through MCP**: Reader or Spider.cloud. Both expose browser session tools. Spider.cloud has more granular browser control (9 separate tools). Reader offers full CDP sessions.

**Need the broadest tool set**: Spider.cloud (22 tools) or Firecrawl (12 tools). Both cover scraping, crawling, and browser automation in a single MCP server.

**Need strongest anti-bot**: ZenRows. Their single tool with Adaptive Stealth Mode is purpose-built for protected sites.

**Need dedicated site scrapers**: ScrapingBee (Google, Amazon, Walmart tools) or Apify (thousands of site-specific Actors).

**Need open source and self-hostable**: Reader (Apache 2.0, fully self-hostable) or Spider.cloud (MIT license for the crawler engine).

## Conclusion

MCP servers have quickly become essential infrastructure for AI developers who need web access. With 97 million monthly SDK downloads and support across every major AI coding tool, MCP is no longer optional. It is how AI tools interact with external services.

For web scraping specifically, the choice depends on what you need your AI assistant to do. Reader and Spider.cloud offer the most complete browser automation through MCP. Firecrawl offers the broadest tool set. ZenRows handles the hardest anti-bot challenges. ScrapingBee and Apify provide access to site-specific scrapers.

Most MCP clients support multiple servers simultaneously, so you do not have to pick just one. Install Reader for general scraping and browser automation, add ZenRows for protected sites, and use Apify when you need a site-specific Actor. Your AI assistant will route to the right tool based on the task.
