The Model Context Protocol is how AI tools talk to external services. Reader's MCP server gives any MCP compatible client the ability to scrape, crawl, extract, and automate the web through nine tools. Install it once and it works across Claude Code, Claude Desktop, Cursor, VS Code, Windsurf, Codex, and OpenCode.

## What Is MCP

The Model Context Protocol is an open standard introduced by Anthropic on November 25, 2024 and donated to the Linux Foundation's Agentic AI Foundation on December 9, 2025. The foundation was co founded by Anthropic, OpenAI, and Block, with AWS, Google, Microsoft, Cloudflare, and Bloomberg as supporting members.

MCP solves a specific problem. Without it, every AI tool needs custom integrations for every external service. N tools times M services equals N times M custom connectors. MCP replaces that with a single protocol. Any MCP compatible client can call any MCP server using the same interface.

As of December 2025, the MCP ecosystem had over 97 million monthly SDK downloads and 10,000 active servers. It is supported by Claude (Code and Desktop), ChatGPT, Cursor, Windsurf, VS Code, Gemini, Microsoft Copilot, Codex, Cline, Zed, Replit, Continue.dev, and JetBrains AI Assistant.

For web scraping, this means your AI coding assistant can scrape pages, crawl sites, extract structured data, and control browser sessions through a single installed MCP server, regardless of which AI tool you use.

## Installation for Each Client

### Claude Code

The simplest installation. One terminal command:

```bash
claude mcp add reader -- npx -y @vakra-dev/reader-mcp
```

Set your API key:

```bash
export READER_API_KEY=rdr_your_key
```

Or pass it during setup:

```bash
claude mcp add reader --env READER_API_KEY=rdr_your_key -- npx -y @vakra-dev/reader-mcp
```

Verify with `claude mcp list`.

### Claude Desktop

Add to your Claude Desktop configuration file.

**macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
**Windows:** `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "reader": {
      "command": "npx",
      "args": ["-y", "@vakra-dev/reader-mcp"],
      "env": {
        "READER_API_KEY": "rdr_your_key"
      }
    }
  }
}
```

Restart Claude Desktop after saving.

### Cursor

Open Cursor Settings, navigate to the MCP section, and add a new server with:

```json
{
  "reader": {
    "command": "npx",
    "args": ["-y", "@vakra-dev/reader-mcp"],
    "env": {
      "READER_API_KEY": "rdr_your_key"
    }
  }
}
```

### VS Code

Configure through the MCP extension settings (Copilot or Continue.dev). Add the same JSON structure to the MCP servers configuration.

### Windsurf, Codex, OpenCode

All follow the same pattern. Add the server entry to the client's MCP configuration with the `npx` command and your API key.

### Project Level Configuration

For team projects, create a `.mcp.json` file at the root of your repository:

```json
{
  "mcpServers": {
    "reader": {
      "command": "npx",
      "args": ["-y", "@vakra-dev/reader-mcp"],
      "env": {
        "READER_API_KEY": "rdr_your_key"
      }
    }
  }
}
```

Commit this file to your repository. Every team member who opens the project in Claude Code or another MCP compatible tool gets Reader's web tools automatically.

## Practical Examples

### Research a library before using it

Ask your AI assistant: "Scrape the axios documentation and explain how interceptors work."

The assistant calls `reader_scrape` with the documentation URL, gets the clean markdown content, and provides an explanation based on the actual current documentation. No outdated training data, no hallucinated API signatures.

### Build a knowledge base from a documentation site

Ask: "Crawl https://docs.reader.dev with max depth 2 and create a summary of all available features."

The assistant calls `reader_crawl`, which discovers and scrapes every page within 2 levels. It then processes all the returned markdown and produces a structured summary. For a documentation site with 30 pages, this gives you a complete overview in about a minute.

### Extract structured data from any page

Ask: "Extract the company name, founding year, and number of employees from this company's about page."

The assistant calls `reader_extract` with a schema defining the fields you want. The response is typed JSON ready for use in your application.

### Test an authenticated workflow

Ask: "Create a browser session and navigate to our staging login page."

The assistant calls `reader_session_create` and gets a CDP WebSocket URL. It can then automate browser interactions: filling forms, clicking buttons, navigating pages. The session persists across multiple tool calls.

## Using Multiple MCP Servers Together

Most MCP clients support multiple servers simultaneously. You can install Reader for web scraping alongside other MCP servers for different capabilities.

A typical development setup might include Reader MCP for web access, a GitHub MCP for repository operations, a database MCP for data queries, and a file system MCP for local file management. Your AI assistant routes to the right server based on the task.

For example: "Scrape this documentation site (Reader), extract the key API changes (Reader extract), and create a PR summarizing the changes (GitHub MCP)." The assistant orchestrates calls across multiple servers to complete the workflow.
