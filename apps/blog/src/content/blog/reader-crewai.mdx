CrewAI is a framework for building multi agent systems where specialized agents collaborate on complex tasks. A researcher agent gathers information. An analyst agent processes it. A writer agent produces the output. Each agent has a role, a goal, and tools it can use.

Agents without web access are limited to their training data. Agents with web access can check current prices, read documentation, monitor competitors, and gather live information. Reader provides that web access through tools that CrewAI agents can call during their reasoning: scrape pages to markdown, crawl sites for comprehensive research, and extract structured data from any URL.

This guide shows how to build Reader tools for CrewAI, create web aware agents, and assemble crews for practical workflows.

## Building Reader Tools for CrewAI

CrewAI agents use tools to interact with external systems. Wrap Reader's capabilities as CrewAI tools.

### Scrape Tool

```python
from crewai.tools import tool
from reader_py import ReaderClient

reader_client = ReaderClient(api_key=os.environ.get("READER_API_KEY"))

@tool("Scrape Web Page")
def scrape_page(url: str) -> str:
    """Scrape a web page and return its content as clean markdown.
    Use this to read any web page including JavaScript-rendered sites.
    Input should be a valid URL starting with http:// or https://."""
    try:
        result = reader_client.read(url=url)
        content = result.data.markdown
        # Truncate for context window management
        if len(content) > 15000:
            content = content[:15000] + "\n\n[Content truncated for length]"
        return content
    except Exception as e:
        return f"Failed to scrape {url}: {str(e)}"
```

### Extract Tool

```python
import json

@tool("Extract Structured Data")
def extract_data(url: str) -> str:
    """Extract structured data from a web page. Returns JSON with
    the key information found on the page including titles, prices,
    descriptions, and other structured fields.
    Input should be a valid URL."""
    try:
        result = reader_client.read(
            url=url,
            extract={
                "prompt": "Extract the key structured data from this page "
                          "including any names, prices, dates, descriptions, "
                          "ratings, and other factual information."
            }
        )
        if result.data.extracted:
            return json.dumps(result.data.extracted, indent=2)
        return result.data.markdown[:5000]
    except Exception as e:
        return f"Failed to extract from {url}: {str(e)}"
```

### Crawl Tool

```python
@tool("Crawl Website")
def crawl_site(url: str) -> str:
    """Crawl a website and return summaries of all discovered pages.
    Use this to understand the full scope of a website's content.
    Discovers up to 20 pages. Input should be the website's root URL."""
    try:
        result = reader_client.read(
            url=url,
            max_depth=2,
            max_pages=20,
        )
        summaries = []
        for page in result.data:
            title = page.metadata.title if page.metadata else page.url
            preview = page.markdown[:300] if page.markdown else ""
            summaries.append(f"**{title}**\nURL: {page.url}\n{preview}...")

        return "\n\n---\n\n".join(summaries)
    except Exception as e:
        return f"Failed to crawl {url}: {str(e)}"
```

### Tool Descriptions Matter

CrewAI agents decide which tool to use based on the tool's description. Write clear, specific descriptions that tell the agent when to use each tool:

- **Scrape:** "read any web page" signals single page reading
- **Extract:** "structured data" and "JSON" signal when the agent needs typed fields
- **Crawl:** "full scope" and "all discovered pages" signal comprehensive research

Vague descriptions cause agents to pick the wrong tool. Specific descriptions lead to better tool selection.

## Creating Web Aware Agents

CrewAI agents have a role, goal, backstory, and tools. The role and backstory guide the agent's behavior. The tools define what it can do.

### Researcher Agent

```python
from crewai import Agent

researcher = Agent(
    role="Web Researcher",
    goal="Find accurate, current information from the web to support analysis",
    backstory=(
        "You are a thorough web researcher who uses scraping tools to "
        "gather information from websites. You verify facts by checking "
        "multiple sources. You focus on extracting the most relevant "
        "information and presenting it clearly."
    ),
    tools=[scrape_page, extract_data, crawl_site],
    verbose=True,
)
```

### Analyst Agent

```python
analyst = Agent(

```

### Writer Agent

writer = Agent(

Not every agent needs web tools. The researcher gathers data from the web. The analyst and writer work with the data the researcher provides. Giving every agent scraping tools wastes credits and creates redundant web requests.

## Building Crews for Practical Workflows

### Competitor Analysis Crew

A crew that researches competitors, analyzes their positioning, and produces a report.

```python
from crewai import Crew, Task

# Task 1: Research competitor websites
research_task = Task(
    description=(
        "Research these competitor websites and gather information about "
        "their pricing, features, positioning, and target audience:\n"
        "1. https://competitor-a.com\n"
        "2. https://competitor-b.com\n"
        "3. https://competitor-c.com\n\n"
        "For each competitor, scrape their homepage and pricing page. "
        "Extract pricing data (plan names, prices, features) as structured data. "
        "Note their positioning (tagline, value proposition, target audience)."
    ),
    expected_output=(
        "A detailed summary of each competitor's pricing, features, "
        "and positioning with specific data points."
    ),
    agent=researcher,
)

# Task 2: Analyze the competitive landscape
analysis_task = Task(
    description=(
        "Analyze the competitor research and identify:\n"
        "- How competitors price relative to each other\n"
        "- Feature gaps and overlaps\n"
        "- Positioning differences (who targets developers vs enterprises)\n"
        "- Opportunities for differentiation"
    ),
    expected_output=(
        "A competitive analysis with specific comparisons, identified "
        "gaps, and strategic recommendations."
    ),
    agent=analyst,
    context=[research_task],  # Receives output from research
)

# Task 3: Write the report
report_task = Task(
    description=(
        "Write a competitive intelligence report based on the research "
        "and analysis. Include an executive summary, competitor profiles, "
        "comparison table, and recommendations."
    ),
    expected_output="A well-structured competitive intelligence report.",
    agent=writer,
    context=[research_task, analysis_task],
)

# Assemble and run
crew = Crew(
    agents=[researcher, analyst, writer],
    tasks=[research_task, analysis_task, report_task],
    verbose=True,
)

result = crew.kickoff()
print(result)
```

The researcher scrapes competitor sites (6 pages: 3 homepages + 3 pricing pages). The analyst receives the research and identifies patterns. The writer produces the report. Each agent specializes in its role.

## Managing Token Usage

Web content is large. A single scraped page can be 5,000 to 15,000 tokens. CrewAI agents pass context between tasks, and accumulated web content can exceed context window limits.

### Truncation

The scrape tool already truncates at 15,000 characters. Adjust this limit based on your model's context window and the number of pages the crew scrapes per run.

### Use Extract Instead of Scrape

When agents need specific data points rather than full page content, use the extract tool. Extracted JSON is 50 to 200 tokens vs 3,000 to 10,000 tokens for full markdown.

```python
# Instead of scraping the full pricing page (5,000+ tokens)
# Extract just the pricing data (200 tokens)
extract_task = Task(
    description=(
        "Extract pricing data from https://competitor.com/pricing. "
        "Use the Extract tool to get plan names, prices, and features "
        "as structured JSON."
    ),
    agent=researcher,
)
```

### Limit Crawl Scope

Keep `max_pages` low (10 to 30) for crawl tasks. The crawl tool returns summaries (first 300 characters per page), not full content, which helps manage context size. If the agent needs full content from specific pages discovered during crawl, it can scrape those individually.

## Error Handling

Web scraping fails. Pages block requests, URLs change, sites go down. The tool implementations above include try/except blocks that return error messages instead of crashing the agent. The agent sees the error message and can decide to try a different URL, skip the source, or report the failure.

For production crews, add retry logic inside the tools:

```python
import time

@tool("Scrape Web Page")
def scrape_page_with_retry(url: str) -> str:
    """Scrape a web page with automatic retry on failure."""
    for attempt in range(3):
        try:
            result = reader_client.read(url=url)
            content = result.data.markdown
            if len(content) > 15000:
                content = content[:15000] + "\n\n[Truncated]"
            return content
        except Exception as e:
            if attempt < 2:
                time.sleep(2 ** attempt)
                continue
            return f"Failed after 3 attempts: {str(e)}"
```

## Conclusion

CrewAI's multi agent architecture maps naturally to web research workflows. The researcher gathers data from the web using Reader tools. The analyst processes and compares the data. The writer produces the output. Each agent specializes, and context flows between tasks automatically.

Reader provides three tools that cover the full range of web access: scrape for reading specific pages, extract for pulling structured data, and crawl for comprehensive site research. The clean markdown output fits naturally into CrewAI's context passing because it is token efficient and LLM readable without preprocessing.

Start with a two agent crew (researcher + analyst) and one or two tools (scrape + extract). Add complexity as the workflow proves value. Most practical CrewAI workflows need fewer agents and tools than you initially expect.
